# الفكتيرة

تطبيق فوترة ومحاسبة عربي قابل للتثبيت (PWA) مع موقع التحميل. لا يحتاج خادماً ولا قاعدة بيانات: ملفات ثابتة تُرفع على أي استضافة.

## المحتويات

| الملف | الدور |
|---|---|
| `index.html` | موقع التحميل: المزايا، الأسعار، زر التثبيت، الأسئلة |
| `app/index.html` | التطبيق: الفواتير، العملاء، المنتجات، المصروفات، التقارير، الاشتراك، الإعدادات |
| `config.js` | **الملف الوحيد الذي تعدّله**: رقم واتساب، البريد، الأسعار، طرق الدفع |
| `manifest.webmanifest`, `sw.js`, `icons/` | ما يجعل الموقع تطبيقاً قابلاً للتثبيت ويعمل دون إنترنت |
| `shots/` | لقطات التطبيق المعروضة في الموقع ونافذة التثبيت |

## النشر

يجب أن يُنشر عبر **HTTPS** (شرط التثبيت).

- **Netlify Drop** (الأسرع): اسحب مجلد المشروع إلى https://app.netlify.com/drop فتحصل على رابط فوراً، ثم اربط نطاقك (مثل `faktira.mr`).
- **GitHub Pages**: الإعدادات ← Pages ← Deploy from a branch ← `main` / `root`. (المستودع الخاص يحتاج اشتراك GitHub مدفوعاً لتفعيل Pages.)
- **Cloudflare Pages** أو أي استضافة ملفات ثابتة.

## عند كل تحديث

غيّر `VERSION` في `sw.js` (مثلاً `faktira-v2`) حتى يحصل المستخدمون المثبِّتون على النسخة الجديدة.

## البيانات

تُحفظ بيانات كل مستخدم في متصفحه (`localStorage`) على جهازه. صفحة الإعدادات في التطبيق تصدّر نسخة احتياطية JSON وتستعيدها.

## المرحلة التالية

- حسابات ومزامنة سحابية بين الأجهزة.
- تفعيل الاشتراكات وحدود الباقات من الخادم (الحدود حالياً معروضة فقط ولا تُفرض).
- الواجهة والفاتورة بالفرنسية، وفاتورة PDF مباشرة.
