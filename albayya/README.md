# البياع

موقع إعلانات بيع وشراء في موريتانيا (سيارات، عقارات، هواتف، مواشي، أثاث، وظائف، خدمات). ملفات ثابتة تُرفع على أي استضافة HTTPS ويمكن تثبيتها كتطبيق.

| الملف | الدور |
|---|---|
| `index.html` | الموقع: البحث، الأقسام، إعلانات مميزة، تصفية (قسم، مدينة، سعر، حالة، صور)، صفحة الإعلان (صور، مواصفات، بطاقة المعلن، اتصال وواتساب، مشاركة، إعلانات مشابهة)، المفضلة، نموذج «أضف إعلان»، «إعلاناتي» |
| `config.js` | الاسم، رقم واتساب الإدارة، المدن، الأقسام، شريط «إعلانات تجريبية» (`demo`) |
| `catalog.js` | الأنواع الفرعية والمواصفات لكل قسم (ماركات السيارات وموديلاتها، السنة، المسافة، الوقود، الغرف، المساحة، الذاكرة...). منه تُبنى الفلاتر ونموذج النشر وجدول المواصفات |
| `ads.js` | الإعلانات المنشورة للجميع: العنوان، السعر، الحالة، المواصفات، اسم المعلن ورقمه، `featured` للإعلانات المميزة. الصور توضع في `img/` (بدونها يظهر رسم القسم) |
| `icons/icon.svg` | الأيقونة: مشترية بملحفة تناول البائع النقود، وبائع بدراعة زرقاء ولثام نيلي يناولها الكيس، تحت مظلّة دكان. PNG مولّدة منها |
| `supabase/` | قاعدة البيانات: `schema.sql` (الجدول والصلاحيات والصور) و`README.md` (خطوات الربط) |
| `vendor/` | مكتبة Supabase، ولا تُحمَّل إلا بعد ملء `supabase` في `config.js` |
| `manifest.webmanifest`, `sw.js` | التثبيت والعمل دون إنترنت |

## كيف تُنشر الإعلانات

- **مع Supabase** (انظر [`supabase/README.md`](supabase/README.md)): يُحفظ الإعلان في قاعدة البيانات مع صوره، ويظهر للجميع فوراً. ينشر الزائر دون حساب، أو بعد الدخول بالبريد ليدير إعلاناته من أي جهاز.
- **دون Supabase** (إذا كان `supabase` فارغاً في `config.js`): يُحفظ الإعلان على جهاز صاحبه فقط، ويُرسل نصه إلى الإدارة عبر واتساب إن كان `whatsapp` معبّأً، والإدارة تضيفه إلى `ads.js`.

الإعلانات في `ads.js` تظهر دائماً مع إعلانات قاعدة البيانات. عند الإطلاق احذف الأمثلة منها واجعل `demo: false`.
