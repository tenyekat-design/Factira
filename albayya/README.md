# البياع

موقع إعلانات بيع وشراء في موريتانيا (سيارات، عقارات، هواتف، مواشي، أثاث، وظائف، خدمات). ملفات ثابتة تُرفع على أي استضافة HTTPS ويمكن تثبيتها كتطبيق.

| الملف | الدور |
|---|---|
| `index.html` | الموقع: البحث، الأقسام، المدن، صفحة الإعلان (اتصال وواتساب)، نموذج «أضف إعلان»، «إعلاناتي» |
| `config.js` | الاسم، رقم واتساب الإدارة، المدن، الأقسام، شريط «إعلانات تجريبية» (`demo`) |
| `ads.js` | الإعلانات المنشورة للجميع. الصور توضع في `img/` |
| `icons/icon.svg` | الأيقونة: بائع موريتاني فاتح البشرة بدراعة زرقاء مطرّزة ولثام نيلي يغطي الأنف والفم، تحت مظلّة دكان، أمامه بطيخ وبرتقال وبرّاد شاي وتمر. PNG مولّدة منها |
| `manifest.webmanifest`, `sw.js` | التثبيت والعمل دون إنترنت |

## كيف تُنشر الإعلانات

لا يوجد خادم بعد، لذلك:
- إعلان الزائر يُحفظ على جهازه في «إعلاناتي»، وإذا كان `whatsapp` معبّأً في `config.js` يُرسل نصه إلى الإدارة عبر واتساب.
- الإدارة تنسخه إلى `ads.js` (مع صوره في `img/`) فيظهر للجميع، ثم تغيّر `VERSION` في `sw.js`.

عند وضع إعلانات حقيقية: احذف الأمثلة من `ads.js` واجعل `demo: false`. لتلقي الإعلانات ونشرها تلقائياً مع حسابات المستخدمين يلزم لاحقاً خادم وقاعدة بيانات (مثل Supabase أو Firebase).
